# Альфа Инсайт

Персональная новостная аналитика для крупного бизнеса — клиентов Альфа-Банка с выручкой от 15 млрд ₽.
Сервис превращает поток новостей и аналитику Альфа-Банка в инсайты для конкретной компании и конкретного
человека в ней: что произошло, почему это важно именно вам, риски и возможности, что делать и что думает банк.

> Проект в разработке. Полная спецификация — в [`docs/`](docs/README.md), план работ — в
> [`docs/14-backlog.md`](docs/14-backlog.md).

## Быстрый старт (разработка)

```bash
cp .env.example .env   # заполнить LLM_API_KEY и LLM_BASE_URL
make setup             # uv sync + npm ci
make check && make test
```

## Модели и бюджет

Модели шлюза хакатона и их роли — в [`config/models.yaml`](config/models.yaml) и [`docs/04-llm.md`](docs/04-llm.md).
Возможности проверены `alfa llm probe`: все модели поддерживают вызов инструментов и JSON-ответы.
Рассуждения моделей отключены (`reasoning: false`) — это в 10–30 раз дешевле и быстрее.

Расчёт суточной стоимости по формуле `docs/04-llm.md` §7.4 на замеренных ценах (₽ за 1 млн токенов):

| Операция | Модели | ₽ за операцию | В сутки | ₽ в сутки |
|---|---|---|---|---|
| Разметка новости | gemma | 0.025 | 300 | 7.5 |
| Инсайт (pipeline: черновик + проверка) | deepseek + glm | 0.41 | 60 | 24.7 |
| «Проверить новость» (agentic: разметка, 2 раунда, проверка) | gemma + deepseek + glm | 0.62 | 40 | 24.8 |
| Чат | deepseek | 0.25 | 30 | 7.5 |
| **Итого** | | | | **≈ 65 ₽** |

Разовая обработка 9 PDF Альфа-Банка (qwen_text) — около 20 ₽. Суточный лимит в коде — 450 ₽ из 500 ₽,
последние 150 ₽ зарезервированы под интерактивные запросы. Запас большой, поэтому рычаги экономии из
§7.4 пока не нужны. Остаток и траты: `uv run alfa llm budget`.
